## 1. 背景与设计结论

用户已选定 A 方向「甜辣拼贴档案」，并明确要求整体更粉嫩，因为目标对象喜欢粉色。

最终设计采用「草莓牛奶粉心动档案」：保留参考图中的档案袋、撕纸、回形针、橡皮章、粗黑线、贴纸和手绘涂鸦；把原本占主导的黄色降为少量标签色，以草莓牛奶粉、珊瑚粉和奶油白构成主画面。

整条流程不是若干独立白卡，而是一份逐页推进的「心动案件档案」：递交申请、追捕逃跑按钮、捕捉空闲时间、选择快乐补给、签发约会通行证。角色、文案和动画都服务于同一个叙事。

## 2. 目标

1. 全流程第一眼更粉嫩、更可爱、更接近用户提供的拼贴档案参考图。
2. 毛球管理员从小头像升级为剧情主角，并统一成更幼态、更软萌的角色原型。
3. 「不要」按钮连续逃跑仍是开场核心亮点，并增加轨迹、追捕动作和逐级暧昧文案。
4. 菜单从普通 Emoji 白卡升级为 3×3 撕纸食物档案卡，每张有独立插画、颜色和小情话。
5. 全流程加入含蓄、有创意、不油腻的情话；既能表达喜欢，也保留不好意思的感觉。
6. 保留现有提交、分享、进度恢复和主要状态流，不为视觉改版重写业务逻辑。

## 3. 非目标

- 不增加登录、账号、多人协作或服务端数据库。
- 不改变邀请数据的核心字段：日期、时间、备注和餐食选择。
- 不新增第三方 UI 组件库。
- 不把产品扩展成复杂恋爱游戏；每屏仍只完成一个核心任务。
- 不使用「宝贝、老婆、余生、唯一、命中注定」等过度承诺或默认亲密关系的称呼。

## 4. 视觉系统

### 4.1 色板

| 角色 | 色值 | 用法 |
|---|---:|---|
| 草莓牛奶粉 | `#F8CFDB` | 页面主背景、最大面积色 |
| 文件夹粉 | `#EFA2B7` | 档案袋和中层纸张 |
| 奶油白 | `#FFF9ED` | 主要内容纸、票根、输入区 |
| 心动玫红 | `#ED3F78` | 标题重点、印章、选中态 |
| 珊瑚粉 | `#FF6E8C` | 主按钮、角色呼应色 |
| 便签黄 | `#F4CF5E` | 胶带、少量菜单卡和提示 |
| 薄荷绿 | `#A8DFD3` | 旁白便签、少量菜单卡 |
| 天空蓝 | `#A8D5EF` | 少量菜单卡 |
| 薰衣草紫 | `#D0C3E9` | 少量菜单卡 |
| 墨黑 | `#1C1719` | 文字、粗描边、硬阴影 |

粉色应覆盖约 65% 的首屏可见区域；奶油白约 25%；黄色、薄荷、蓝和紫合计不超过 10%。黄色不能再作为大面积页面底色。

### 4.2 纸张层级

每屏使用三层结构：

1. 底层：粉色档案夹或页面底纸。
2. 中层：略有旋转的奶油白撕纸，承载当前核心任务。
3. 上层：标签、胶带、回形针、印章、虚线和角色贴纸。

装饰必须围绕内容布置，不能遮住按钮、表单或菜单名称。移动端每屏最多同时出现 6 个纯装饰元素。

### 4.3 线条、圆角与阴影

- 主纸张描边：`2px–3px` 墨黑。
- 主按钮描边：`3px` 墨黑。
- 硬阴影：`0 5px 0 #1C1719`，按压时缩短到 `0 2px 0`。
- 纸张可轻微旋转 `-2deg` 到 `2deg`。
- 撕纸使用固定 `clip-path`，避免每次渲染随机导致布局跳动。
- 主按钮保留胶囊形；便签和票根使用不规则纸边，不统一成圆角卡片。

### 4.4 字体层级

- 中文标题继续使用系统黑体，但加大字重和紧凑字距，保持参考图中的粗标题感。
- 英文档案标签使用 Georgia 或等宽衬线回退字体，强化「编号、机密、审批」语义。
- 正文保持可读，不使用难以稳定加载的外部字体。

## 5. 毛球管理员角色系统

### 5.1 新角色原型

正式角色应比现有素材更幼态：

- 头身近似一体，整体更圆、更蓬松。
- 手脚缩短为豆豆手和小短腿。
- 眼睛更大，眼距略宽，腮红更明显。
- 眉毛不再长期呈「执法式严肃」，主要表情以紧张、惊喜、偷笑和装镇定为主。
- 珊瑚粉毛发，奶油白贴纸描边，保留黑领带和心形档案章作为识别物。
- 触角可以随情绪弯成问号、感叹号或心形。
- 每张资产采用相同线宽、颗粒感、光源和毛发质感。

### 5.2 六个剧情姿势

沿用现有 mood key 和文件名，降低代码迁移范围：

| mood | 剧情姿势 | 使用页面 |
|---|---|---|
| `serious` | 抱申请表，努力装镇定 | 开场 |
| `surprised` | 眼睛放大、手捂脸、触角弹起 | 二次确认 |
| `hunter` | 拿放大镜和捕心网追按钮 | 拒绝逃跑、日期页 |
| `chef` | 戴厨师帽、抱碗偷吃 | 菜单页 |
| `courier` | 抱爱心信封奔跑 | 提交中 |
| `cool` | 心形触角、墨镜、开心装酷 | 成功页 |

角色不再放进统一的 `84×84` 方形头像框。各屏按剧情使用 `140px–220px` 的透明贴纸角色，占画面高度约 25%–40%。

## 6. 全流程页面设计

### 6.1 开场：递交见面申请

- 顶部标签：`机密文件 · 仅对你生效`
- 主标题：`请批准一场 / 蓄谋已久的见面`
- 副标题：`我把“想见你”写成了申请表，免得当面又假装随便。`
- 毛球旁白：`申请人表面镇定，实际已经点开页面 18 次。`
- 主按钮：`批准申请 ♥`
- 逃跑按钮初始文案：`暂不批准`

构图使用粉色档案袋作底、奶油撕纸作正文、右下角大尺寸 serious 毛球压住纸边。主按钮固定在下方，拒绝按钮在可活动区域内逃跑。

### 6.2 「不要」按钮连续逃跑

保留现有无限逃跑与 260ms 防抖，但把六个固定点升级为覆盖全卡片的 12 个安全位置。桌面用鼠标靠近触发，触屏用按下触发，键盘激活也能推进。

每次逃跑同时发生：

1. 按钮移动到下一个安全位置。
2. 留下短虚线轨迹和小纸屑。
3. 毛球 hunter 做追扑、扑空或回头动作。
4. 更换按钮文字和旁白。

文案循环共 16 级：

| 级别 | 按钮文字 | 毛球旁白 |
|---:|---|---|
| 0 | 暂不批准 | 拒绝键已就位，看起来不太安分。 |
| 1 | 欸，等一下 | 它说还没做好被点中的准备。 |
| 2 | 我再躲一下 | 申请人没跑，按钮先跑了。 |
| 3 | 这边也点不到 | 你追得这么认真，它开始紧张。 |
| 4 | 你怎么还追呀 | 友情提示：追按钮，也有一点像追。 |
| 5 | 再追就暧昧了 | 档案局开始记录，但不作为证据。 |
| 6 | 让我缓半秒 | 按钮在喘气，申请人在偷笑。 |
| 7 | 你其实在笑吧 | 放心，表情不在采集范围。 |
| 8 | 我快没地方跑了 | 逃跑路线快用完，勇气倒多了一点。 |
| 9 | 批准键在那边 | 左边那个粉色的，看起来很适合你。 |
| 10 | 再想我半秒嘛 | 只见一面，不急着把话都说完。 |
| 11 | 追到这里很可疑 | 到底是谁舍不得结束这段追逐？ |
| 12 | 给你留个台阶 | 点批准不算输，只算一起吃顿饭。 |
| 13 | 我替你保密 | 不会告诉别人，你追了这么久。 |
| 14 | 好啦，不跑了 | 按钮认输，申请人也快装不住了。 |
| 15 | …其实想见吧 | 如果答案是愿意，轻轻点一下就好。 |

达到第 15 级后循环 12–15，避免文案继续升级成负罪感或强迫式表达。按钮仍会继续逃跑。

### 6.3 二次确认：审批异常

- 标签：`审批异常提醒`
- 标题：`等等，你真的批准了？`
- 副标题：`我连被拒绝后的体面台词都准备好了，结果你让我白练了。`
- 毛球旁白：`报告：申请人正在努力不要笑得太明显。`
- 主按钮：`嗯，是真的 ♥`
- 次按钮：`刚刚手滑`

使用 surprised 毛球占据上半屏，触角弹起并出现小纸屑。二次确认保留现有流程，不新增状态。

### 6.4 日期与时间：捕捉空闲

- 标签：`心动线索 · 第 1 项`
- 标题：`正在捕捉你的空闲时间`
- 副标题：`借我一天里的两个小时，剩下的期待我来负责。`
- 日期提示：`哪天适合偷偷见面？`
- 时间提示：`几点开始想你…不是，见你？`
- 备注标签：`给约会管理员留个暗号（可选）`
- 下一步：`抓到了，去选快乐 →`

日期保留原生 `input[type=date]` 的数据和可访问性，但视觉包裹成撕纸日历。时间改为三张可点击票根，不再使用原生下拉框：

- `15:00 · 阳光替我打掩护`
- `19:00 · 晚饭刚好，心动也刚好`
- `20:30 · 夜色负责保密`

选择日期后显示：`这天被圈起来了，旁边不小心多画了一颗心。`  
选择时间后显示对应的小旁白。

### 6.5 菜单：快乐补给

- 标签：`快乐补给 · 第 2 项`
- 标题：`这次的快乐，吃什么？`
- 副标题：`你负责挑喜欢的，我负责把你喜欢的记住。`

菜单固定为 3×3：

| id | 名称 | 卡片小情话 | 选中反馈 |
|---|---|---|---|
| `hotpot` | 火锅 | 把拘谨一起煮开 | 这次见面，得热气腾腾一点。 |
| `sushi` | 日料 | 安静一点，好多看你几眼 | 安静的座位，也许更适合偷偷看你。 |
| `bbq` | 烤肉 | 我负责烤，你负责好看 | 我会认真翻面，也会认真听你说话。 |
| `hunan` | 湘菜 | 辣到脸红，刚好有借口 | 脸红这件事，终于有合理解释。 |
| `western` | 西餐 | 认真约会，假装不紧张 | 那我练习一下，怎么自然地帮你拉椅子。 |
| `dessert` | 甜品 | 聊天不够甜，它来补位 | 看来这次见面可以再甜一点。 |
| `coffee` | 咖啡 | 先聊一杯，舍不得再续杯 | 喝完舍不得走，就再点一杯。 |

每张卡包含独立食物插画、不同粉彩撕纸底色、名称和一行小情话。选中后卡片抬起 `4px`，加玫红描边并盖 `就它了！` 印章。

不再点击后 480ms 自动提交。用户先选中、阅读反馈，再点击底部 `装进约会计划 ♥`，以保留比较和反悔空间。

为兼容旧进度和旧分享链接，读取时进行迁移：

- `pizza → western`
- `dim-sum → snacks`
- `ramen → snacks`
- `mala → hunan`
- `crayfish → hunan`
- `skewers → snacks`

### 6.6 提交中

- 副标题：`别催，申请人正在假装这是一件很平常的事。`

- 标题：`好啦，我们要见面了。`
- 副标题：`这句话看起来很普通，但我已经偷偷开心了很久。`
- 状态：`申请人状态：表面镇定 / 实际心跳超速`
- 说明：`凭此通行证，兑换一次很认真又不太好意思的见面。`
- 主按钮：`分享这份小秘密`
- 次按钮：`保存约会通行证`
- 再看：`再偷看一遍`

日期、时间、菜单和备注排成一张有齿孔和批准章的票根，放进粉色档案袋。cool 毛球压在票根右下角。共享计划页复用同一张通行证，不再维护第二套结果样式。

## 7. 文案系统

采用「双声道」：

- 申请人负责真诚、克制、略害羞的表达。
- 毛球管理员负责吐槽、接梗和替申请人说出不敢说的话。

每屏最多保留一句真正暧昧的主文案，其余文字负责功能和引导。笑点始终落在申请人、系统和逃跑按钮上，不取笑对方，也不使用拒绝会造成伤害的负罪感表达。

所有文案集中到 `src/config/invitation.ts`，组件不再硬编码标题、提交中提示或分享状态。

- `InvitationFlow` 的场景切换和焦点跟随。
- `useInvitationProgress`、状态机、提交服务和分享链接框架。
- Framer Motion 和 `prefers-reduced-motion` 处理。
- `ArchiveButton` 的按压反馈。
- 现有六个 mascot mood key。

### 8.2 新增或演进

1. `SceneFrame` 演进为真正支持页面变体的拼贴外壳；增加纸张、标签、夹子和装饰插槽。
2. 新增 `MascotMoment`：组合大尺寸角色、动作和旁白便签。
3. 新增 `FlirtNote`：统一悄悄话、批注和选择反馈。
4. 新增 `FoodChoiceCard`：封装食物插画、标题、小情话、色调和选中印章。
5. `PlanSummaryCard` 改为通行证票根，继续被成功页和共享页复用。
6. 逃跑按钮位置从固定按钮尺寸改为读取实际 DOM 尺寸，避免长文案溢出活动区。

每个组件只承担一个视觉或交互职责，数据仍由场景组件和状态机管理。

## 9. 动画规则

- 页面切换保持 220–300ms，采用轻微上移和淡入。
- 纸张进场可旋转 1–2 度，但不能持续摇晃。
- 毛球使用轻微呼吸、眨眼或短动作；页面静止后不应有多个装饰同时无限循环。
- 逃跑按钮使用弹簧移动，虚线路径在 350ms 内淡出。
- 食物选中使用抬起、盖章和纸屑三段反馈，总时长不超过 500ms。
- 成功页批准章在 320ms 内落下，随后只保留轻微角色呼吸。
- 开启减少动态效果时，保留位置和状态变化，但移除弹簧、循环漂浮和纸屑动画。

## 10. 可访问性与响应式

- 所有按钮保持至少 `44×44px` 可点击区域。
- 文字和背景对比度优先使用墨黑，不以浅粉文字承载正文。
- 装饰元素全部 `aria-hidden` 且不接收指针事件。
- 角色图片提供描述当前动作的替代文字。
- 键盘激活逃跑按钮时同样推进文案和位置。
- 360、390、430px 三档移动宽度不出现横向滚动；桌面保持最大 430px 的手机舞台。
- 食物网格在小于 360px 时仍保持三列，但缩小图像和间距，不删除选项。
- 打印成功卡时隐藏背景装饰和操作按钮，保留完整通行证。

## 11. 错误与兼容处理

- 食物插画加载失败时回退到现有 `FoodIcon`，不能显示空白卡。
- 旧 localStorage 中的餐食 id 在恢复时按迁移表转换。
- 旧分享链接仍可解析并映射到新菜单名称。
- 提交失败不清空已选日期、时间、备注和菜单。
- 视觉资源生成失败时可以暂时保留现有角色素材，但页面布局和组件边界仍按新角色尺寸实现。

## 12. 测试与验收

### 12.1 单元测试

- 16 级逃跑文案索引和 12 个位置循环。
- 食物旧 id 到新 id 的迁移。
- 新 9 项菜单的 label 和选择反馈映射。
- 日期、时间完整性校验保持不变。
- 分享链接新旧菜单 id 解析。

### 12.2 端到端测试

1. 开场主按钮进入二次确认。
2. 鼠标、触摸和键盘都能让拒绝按钮连续逃跑。
3. 至少连续触发 18 次后仍不越界，且文案按 12–15 循环。
4. 日期和时间未完成时不能进入菜单。
5. 选择菜单不会自动提交；用户可以改选。
6. 点击 `装进约会计划` 后进入提交和成功页。
7. 提交失败可重试且数据保留。
8. 成功页分享、保存和重新查看正常。
9. 旧分享链接映射到正确的新菜单。

### 12.3 视觉验收

在 360×800、390×844、430×932 和 1280×900 截图检查：

- 粉色确实是主色，黄色没有重新变成大面积底色。
- 每屏标题、核心任务、角色和主按钮层级清楚。
- 角色不是小头像，且不遮挡核心控件。
- 3×3 菜单全部可见、可辨认、可点击。
- 拒绝按钮任意一步不越过卡片安全边界。
- 成功通行证可打印，不裁切日期、时间、菜单和备注。

## 13. 最终验收标准

改版只有同时满足以下条件才算完成：

1. 全流程采用草莓牛奶粉拼贴档案风，而不是只改菜单页。
2. 六个剧情角色统一为更可爱的幼态原型，并以大尺寸参与叙事。
3. 拒绝按钮可无限连续逃跑，有 16 级含蓄文案、轨迹和角色追捕反馈。
4. 菜单为 3×3 九项丰富食物档案卡，使用真实插画而非单独 Emoji。
5. 用户能先选、再改、最后主动提交菜单。
6. 开场到成功页均有双声道情话，且文案集中配置。
7. 现有提交、分享、恢复、重试能力没有回归。
8. 单元、lint、类型检查、构建和 E2E 全部通过。
9. 关键移动端和桌面截图经人工视觉检查通过。
